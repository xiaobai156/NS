# 半波及唐朝候选身份修复

原候选匹配的一字容错会把彩虹网“精杀半波”等资料列给超级赢家半波波，把红人馆“禁半个波色”列给黄大仙半波，并把唐朝肖、尾、头、行、波互相列为候选。此次310期审计中的正式值仍正确，本次修复防止模板回退时使用这些错误候选。

## 修复范围

- 超级赢家半波波须出现完整印刷标题“大赢家【绝杀半波】”；黄大仙半波须出现“黄大仙--杀半个波色”。只识别半波通用词不再入选。
- 嫣然六合彩大全唐朝四项按“唐朝杀一肖／一尾／一头／一行”各自完整标题识别。“唐朝杀一波”不属于四项中的任何一项。
- 已复核的“唐朝杀一当”标题误读，仅在同图存在完整“唐朝绝杀＋重复三次的同一生肖＋肖稳杀”字段且没有其他唐朝类型标题时接受；不扩大为任意一字容错。
- 标题允许空格、标点、简繁及同区域OCR分段，不得跨物理区域拼接。文字候选、目录回退、单条复抓和汇总表候选扩展遵循同一身份门槛。绿杀及地域两肖也不能借汇总表扩展绕过此前约束。
