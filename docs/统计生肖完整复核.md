# 统计生肖完整复核

品鉴、小慧慧、灰灰团的314期卡面总量与逐肖次数之和不符，但真实明细最高次数均为鸡。原先按总量严格判缺失会拒绝这些卡；只允许差1又会放过次数误读，因此改为按完整证据核对。

- 最高次数的所有不同生肖均输出，并列数量不限。分发仍按现有 JSON 的生肖数量限制执行，未新增三肖以上的目的地。
- 单份 OCR 或纯文字在印刷总量不符时仍缺失。仅同一源图和实际输入的 medium/云主读与独立 small，各自确认同一物理统计块、完整12生肖及次数（含0次）全部相同，才接受主读结果。small 只核对，不能补值或替代主读。
- 无固定总量容差。跨作者、跨期、混合期表头、多次数同框、未知载荷、同肖不同次数、完整性或几何不一致均拒绝。续行生肖参与真正的总量计算。
- 本地首读、原图复读、本机复抓在云名单生成前核对；普通云、主备云复抓和缓存复用走同一裁决入口。CUDA故障和图像处理期间变化继续上抛。
- 云缓存保存独立核对证据；所有统计结果状态保存可重验的主证据。提取契约版本提升到20，旧成功不得直接恢复，原冲突保护保留。
